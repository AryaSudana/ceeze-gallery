Pengaturan Google Drive API

Untuk membaca isi folder Google Drive secara langsung, kamu butuh Google Drive API Key gratis dari Google Cloud Console.

Kunci ini disimpan aman hanya di browser kamu (localStorage) dan tidak dikirim ke server pihak ketiga.

Cara Cepat Dapatkan API Key Gratis:
  1. Buka console.cloud.google.com
  2. Aktifkan Google Drive API pada Library.
  3. Buka menu Credentials > klik Create Credentials > pilih API Key.
